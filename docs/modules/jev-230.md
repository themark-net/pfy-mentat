# Module: Jev-style decision layer (`scripts/pfy_jev_230.py`)

**Architecture layer:** Operator-stack middleware (beside Gab cloud + local recommend).  
**Code:** `scripts/pfy_jev_230.py`  
**Related:** #230 · [ADR-0016](../adr/0016-jev-decision-layer.md) · [ops/jev-230.md](../ops/jev-230.md)

## Operator

### What it does

Typed Choice/Score decision layer for coding sessions: compact tool context, then choose model/tool with a calibrated **margin** (not percent-correct). Primary local attach is **CUA-S1-FORMS**. TypeSafe Jev is optional cloud. mini-jev is a teaching fallback.

### How to run

```bash
python3 scripts/pfy_jev_230.py --selftest
./pfy decision smoke
./pfy decision cua-s1-forms
```

`./pfy decision route` exits 0=ready, 3=escalate (conf low, not broken), 1=fail (#230 · ADR-0016).

`./pfy build -p "<prompt>"` wraps local jev toolset + decision shadow + `grok -p` with `--output-format plain` (#230 · ADR-0016). Default prompt preamble is trimmed (#263); `PFY_BUILD_FULL_PREAMBLE=1` inlines the jev skill bodies and keeps the real GROK_HOME. Receipt records `preamble_tokens_est` (chars/4) separate from the task prompt.

The trimmed child home also exposes `bundled/` as a real directory of byte copies from the real home's `bundled/` (#265), plus a real-file pointer at `skills/pfy-jev-decision/SKILL.md` and a byte copy of `auth.json`. Dest bundled copies are chmod `a-w`. File symlinks are not used (they wrote through into the real tree). User skills are left out. Receipt fields `skills_bundle_chars` / `skills_bundle_tokens_est` (method `chars/4`) count the dest copies' text, not a symlink follow-out, separate from the preamble and the task. `PFY_BUILD_FULL_SKILLS=1` restores the previous pointer-only child home (no bundled tree, real GROK_HOME not kept). A live run whose `bundled/` is missing exits 1 with receipt reason `bundled_missing`.

### Failure modes

| Symptom | Likely cause | Recovery |
|---------|--------------|----------|
| FAIL key missing (optional) | TypeSafe path, no `TYPESAFE_API_KEY` | set key or switch CUA-S1-FORMS |
| ESCALATE conf low (exit **3**) | margin below ~0.85 gate | valid outcome, not broken; confirm, raise bar, or fallback — no silent auto-act |
| FAIL empty form | fixture/runtime missing | `scripts/fixtures/cua_s1_forms_v0.json` |
| `./pfy build -p` preamble huge | `PFY_BUILD_FULL_PREAMBLE=1`, or the grok child still sees the real skills tree | unset the flag (default trimmed). Child home is `pipelines/dogfood/build/<ts>/grok-home` (pointer skill, auth byte copy, bundled byte copies) |
| `./pfy build -p` exits 1, reason `bundled_missing` | trimmed live run and `real_home/bundled` is missing or not a directory | restore that `bundled/` tree, or set `PFY_BUILD_FULL_SKILLS=1` for pointer-only isolation |

## Configuration / variables

| Name | Where | Purpose |
|------|-------|---------|
| `TYPESAFE_API_KEY` | env (secret, optional) | TypeSafe cloud; never required for smoke |
| `PFY_JEV_MODEL` | env | default `jev-1.13.0` |
| `PFY_JEV_CONF_GATE` | env | default `0.85` |
| `PFY_JEV_OFFLINE` | env / CI | skip TypeSafe network |
| `PFY_STATE_DIR` | `decision-layer.json`, `decision-queue.jsonl` | path + local queue |
| `PFY_BUILD_FULL_PREAMBLE` | env | `1` inlines jev skill bodies into `./pfy build -p` and keeps the real GROK_HOME; default is trimmed |
| `PFY_BUILD_FULL_SKILLS` | env | `1` uses the D3 pointer-only child home (no bundled expose, real GROK_HOME not kept). Default byte-copies `bundled/` into the child home (`a-w` on those copies) |

### Entry 080: MCO — CLI-first multi-model parallel orchestration for coding agents

- **URL**: https://x.com/i/status/2086658221825995181
- **Date**: 2026-08-10
- **Poster**: Tom Dörr (@tom_doerr)
- **Summary / Key Claims**: Orchestrates AI coding agents by running selected models/providers in parallel on one task and comparing their raw answers before acting. Lightweight CLI-first layer (not itself a coding agent). Supports review, implement (write mode), chaining/division, and debate-style workflows. Works from terminal or from another agent (Claude Code, Codex, Cursor, Pi, OpenClaw, etc.).
- **Extracted Repos / Tools**: https://github.com/mco-org/mco (MIT, ~450–480★, Python 3.10+ + Node components; install `npx @tt-a1i/mco@latest install` or `pip install -e .`; providers must be pre-installed/authenticated).
- **TOOLS.md Link**: Proposed under Agent Frameworks & Orchestration / Multi-Model & Parallel Orchestration (initial scores: S1=85 S2=70 S3=88 S4=78 overall ~81 tier A/B). Tracking: proposed pin to latest main or npm tag.
- **Notes**: Stage 0 gate **PASS** (MIT; documented one-liner install + `mco doctor` / `mco review` / `mco run` hello-worlds that exercise parallel providers and raw-answer retention). High relevance: multi-provider parallel + raw comparison without auto-synthesis is a clean complement to model routers (Not Diamond) and multi-harness workspaces (holaOS). Depends on external agent CLIs (Claude/Codex/Pi/etc.) being present — not pure local-only, but fully self-hostable once providers are set up. No built-in sandbox; relies on provider isolation + `--allow-paths`. Thread note (reply): "并行跑不难，怎么比 raw answers 才是难点" — comparison UX is the real hard part; MCO deliberately keeps raw answers for human/agent inspection rather than auto-merging. Recommend: (1) catalog as A/B multi-model orchestration utility; (2) smoke-test `mco review --providers ...` against a small local repo with 2+ providers; (3) no deeper eval queued unless integration friction appears. Strong fit for Grok CLI + multi-backend pipelines where blind-spot reduction via parallel perspectives matters.
